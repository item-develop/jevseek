# 02. UI — シンプルで洗練、YouTube の中で浮かない

## 原則

1. **色は 1 つだけ足す。** アクセント（`--jevseek-accent`、既定はミント `#5eead4`）を、名前・枠・選択行・確率バー・ヒートに使う。それ以外は白の透明度。YouTube の赤とは離れた色相にして喧嘩させない
2. **文字と線だけ。** アイコン・イラスト・ロゴを置かない。唯一の"絵"はシークバーの山
3. **YouTube の寸法に合わせる。** 角丸 12px、パネル地は `rgba(15,15,15,.88)`＋blur、フォントは `"YouTube Sans","Roboto"`。プレイヤーの一部に見えること
4. **動きは 2 つだけ。** パネルの出現（opacity 120ms）と山の出現（opacity 160ms）。行の出入りにアニメーションを付けない
5. **状態は文で伝える。** 空・エラー・ロード中は小さな灰色の 1 行。モーダルもトーストも出さない

## トークン（styles.css がこれを実装している）

| 名前 | 値 | 用途 |
| --- | --- | --- |
| accent | `#5eead4`（`--jevseek-accent` / `--jevseek-accent-rgb`。styles.css の 1 行で差し替え） | 名前、枠線、選択行、確率バー、ヒート、トリガー |
| surface | `rgba(15,15,15,0.94)` + `backdrop-filter: blur(16px) saturate(1.2)` + 影 `0 12px 40px rgba(0,0,0,.55)` | パネル |
| hairline | `rgba(accent, 0.35)`（枠）/ `rgba(accent, 0.18)`（区切り） | 枠線、区切り |
| text | `#f1f1f1` | 主文字、時刻 |
| text-2 | `#aaaaaa` | 抜粋 |
| text-3 | `#717171` | プレースホルダ、メタ、ステータス |
| hover / selected | `rgba(255,255,255,0.07)` / `rgba(accent, 0.14)` | 行のホバー／選択（選択行の時刻は accent） |
| radius | 12px（パネル）/ 8px（行）/ 14px（ピル） | |
| type | 入力 15px / 行 13px / 時刻 12px tabular-nums / メタ 11px | 太字なし |
| heat | `rgba(accent, 0.25 + 0.7·p)`、高さ 3 + 13·p px | シークバー上 |
| focus | 1px `#fff` outline, offset 2px | キーボード可視 |

## レイアウト（プレイヤー内・右上）

```
┌ #movie_player ────────────────────────────────────────────┐
│                                       ┌──────────────────┐ │
│                                       │ jevSeek Where in this… 0.4s│ │  ← 名前(11px 灰) + 入力 + 右端にレイテンシ
│                                       ├──────────────────┤ │
│                                       │ 3:06  ボディだけで… ▬ │ │  ← 時刻 / 抜粋 1 行 / 確率バー(2px)

│                                       │ 8:12  値段は高いけ… ▬ │ │
│                                       │ 30 segments · captions ja│ │  ← ステータス（11px 灰）
│                                       └──────────────────┘ │
│                                                             │
│  ▁▁▁▁▂▅█▆▂▁▁▁▁▁▁▂▃▁▁▁▁▁▁▁▁▁▁▁▂▁                              │  ← 熱量（白、シークバーの直上）

```

- パネル幅 380px。ヒットは最大 5 行。抜粋は 1 行で省略
- 選択中／ホバー中のヒットは、シークバー上に **2px の白い縦線** で位置を示す
- 待機中はプレイヤー右上に小さなピル「Find」（accent 文字・枠）だけ。ツールバーの拡張機能アイコンでも開閉できる。プレイヤーにホバーしたときだけ見える（YouTube のコントロールと同じ振る舞い）

## 操作

| 操作 | 結果 |
| --- | --- |
| ⌘⇧F / Ctrl+Shift+F（watch ページ） | パネルを開閉。開いたら入力にフォーカス |
| 入力 | 220ms 後に検索。前の検索は中断。空ならヒートを消す |
| ↑ ↓ | ヒットの選択。シークバーの縦線が動く |
| Enter | 選択中のヒットへ（1.5 秒手前から再生） |
| クリック（行） | 同上 |
| Esc | 閉じる |

入力中は YouTube のショートカット（k, f, j, l, 数字キー）を **止める**（`stopPropagation`）。

## 状態の文言

| 状態 | 文言（ステータス行） |
| --- | --- |
| 字幕読み込み完了 | `30 segments · auto captions ja` |
| 字幕なし | `This video has no captions` |
| サーバー未起動 | `Can't reach the server (npm run dev)` |
| ヒットなし・話題なし（any < 0.3） | `This video doesn't seem to talk about that` |
| ヒットなし・話題あり | `No clear moment found` |
| Mock 動作 | メタ欄に `0.0s · mock` |

## やらないこと

- 2 色目、色付きのヒートマップ（緑→赤）、グラデーション、グロー
- パネルのドラッグ移動、リサイズ、設定画面
- 「AI」「Jev」の文字をパネルに出す（拡張機能名 `jevSeek` を入力行の左に 11px 灰で置くだけで十分）
- スケルトン、スピナー。読み込みはメタ欄の `…` で足りる
- 全画面時の特別扱い（同じ CSS で動く）
