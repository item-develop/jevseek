# 01. プロダクト — jevSeek

## 一言で

**動画に Ctrl+F を。** YouTube の動画で「値段を言ったところ」「話が脱線してるところ」と打つと、その秒数の候補が出て、シークバーに山が立つ。

## なぜ今か

- Jev（TypeSafe AI）は文章を生成せず、1 リクエストで数百の yes/no・段階・選択を並列に返す。字幕を 20〜30 秒のセグメントに切って「このセグメントはその話をしているか」を全部同時に聞ける
- 文字列一致では「脱線」「困っている」「値段を言った瞬間」は探せない。**述語で動画に問える**のが新しさ
- 元ネタ：Jev コミュニティで話題になった「Find in page by meaning」（ページの全文をセンテンス単位で確率づけする Ctrl+F）。動画にはそもそも Ctrl+F が無いので、痛みが大きい
- Vercel AI Gateway で `typesafe-ai/jev` が使える（AI SDK 7 の `experimental_evaluate`）。ウェイトリスト待ちなしで今日動く

## 体験（デモの 15 秒）

1. 長い対談動画を開く。⌘⇧F でパネルが出る
2. 「値段を言ったところ」と打つ。打っている途中から候補と山が動く（220ms デバウンス、0.5 秒前後で結果）
3. 「話が脱線してるところ」に打ち替える。山が別の場所に移る
4. 一番上をクリック。本人がそう言う瞬間に飛ぶ

**打鍵に追従して山が動く**ことが Jev の速さの証明で、ここが見せ場。

## v1 の範囲

- YouTube の watch ページ。字幕（手動 or 自動生成）がある動画
- 日本語・英語（他言語も字幕があれば動く）
- Chrome 拡張（デベロッパーモードで読み込み）＋ ローカルサーバー（AI Gateway のキーを持つ）
- CLI で同じ検索をブラウザなしで回せる（検証用）

## v1 でやらないこと

- 字幕なし動画の文字起こし（Whisper）
- チャンネル横断検索、複数動画の一括
- ストア配布、認証、課金
- 要約・回答の生成（Jev は選ぶだけ。文章は作らない）

## 差別化の置き方

- YouTube 自体の「この動画について質問」（地域限定）はチャット。こちらは **検索**。打つたびに全セグメントを再判定してバーに描く速さの体験は別物。「質問」ではなく「探す」の顔にする
- 既存の文字起こし検索ツールは文字列一致か埋め込み類似。こちらは述語（「困っているところ」）に答え、確信度をそのまま UI に出す
- 名乗り：「テキスト版の動画版」とは言わない。「動画に Ctrl+F を」の一言で独立させる

## 次の一手（v1 が動いた後）

- 述語プリセット（「値段」「脱線」「本題」「笑い」「結論」）をパネルに 4 つ並べる
- 「話題が変わる境目か」を全セグメントに聞いて自動チャプター（同じ 1 リクエストに同居できる）
- ヒットの `?t=` 付き URL コピー
