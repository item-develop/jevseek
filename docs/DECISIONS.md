# 決定記録

形式：`- YYYY-MM-DD [仮定|決定|変更] 内容 — 理由`

- 2026-09-21 [決定] Jev は Vercel AI Gateway 経由（AI SDK `experimental_evaluate`）。TypeSafe 直叩きや SDK は使わない — 今日動くこと、キーが 1 つで済むこと
- 2026-09-21 [決定] セグメント質問の既定は boolean — P(true) がそのまま熱量になり閾値が単純。score は eval で比較して切り替える
- 2026-09-21 [決定] 平滑化はピークを下げない（max） — 孤立ヒットが閾値を割るのを避けるため
- 2026-09-21 [決定] 拡張機能はページ内で字幕を取り、サーバーは YouTube を見に行かない — サーバー側取得は壊れやすいので CLI 専用
- 2026-09-21 [決定] UI は白の透明度のみ、アクセント色なし — YouTube の中で浮かせない
- 2026-09-21 [変更] 字幕本文は 3 段構え（直接 fetch → get_transcript → プレイヤーに読ませて横取り）— `baseUrl` の直接 fetch が `pot` 無しで空を返すようになったため。docs/04
- 2026-09-21 [決定] content script は localhost を直接叩かず service worker 経由 — youtube.com からの CORS プリフライトとローカルネットワークアクセス許可を避ける。port の切断をそのまま中断にする
- 2026-09-21 [決定] 拡張機能の DOM 生成に innerHTML を使わない — YouTube は Trusted Types を強制しており、文字列代入が例外になる環境がある
- 2026-09-21 [仮定] 自動操作 Chrome では YouTube が字幕系 API を止める（timedtext 空、get_transcript 400）— 字幕経路の実証は普段の Chrome で行う
- 2026-09-21 [決定] 拡張機能に表示する文言（placeholder・ステータス・エラー）は英語 — 動画の言語を問わず同じ UI にする
- 2026-09-21 [変更] Gateway のモデル ID は `typesafe-ai/jev`（`jev-latest` は存在せず Model not found になる）— Gateway の /v1/models で確認
- 2026-09-21 [決定] パネルの入力行の左に `jevSeek` を 11px の text-3 で表示 — 何の UI か分かるように。目立たせない
- 2026-09-21 [変更] Jev の 503 / 429 は 300 → 700 → 1500ms で 3 回再試行 — 混雑時に 503 が即返る（同じリクエストが数分後には通る）。SDK の maxRetries は 2 秒からで UI の 8 秒枠に収まらないので自前
- 2026-09-21 [変更] 質問文から「前後のセグメントは文脈として参照してよいが、判断対象は本文」を外し、criteria も「話している / 話していない」に短縮 — 質問文が 1 リクエストの 6 割を占めていたため。eval は before 6/6（P: .95 .73 .70 .98 .96 .97）→ after 6/6（.94 .68 .75 .98 .97 .97）で差なし
- 2026-09-21 [変更] アクセント色を 1 つ入れる（`--jevseek-accent` = ミント #5eead4）— パネルが YouTube に溶けすぎて存在感がなかった。色は CSS 変数 1 行で差し替える。2 色目は足さない
- 2026-09-21 [決定] ツールバーの拡張機能アイコン（action）でもパネルを開閉する — ⌘⇧F を知らなくても辿り着けるように。アイコンは scripts/make-icons.ts で生成（シークバーの上に山）
